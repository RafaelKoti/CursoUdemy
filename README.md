# Curso Udemy — Python do Zero à Inteligência Artificial

Este repositório reúne meus estudos e exercícios desenvolvidos durante o curso **Programação Python: Do Zero à Inteligência Artificial 2026**, disponível na Udemy.

O objetivo é registrar minha evolução na linguagem Python, praticar os conceitos aprendidos e construir uma base sólida para o desenvolvimento de software.

## Estrutura do Repositório

### Classes_poo e Heranca_poo

Conteúdos relacionados à Programação Orientada a Objetos (POO), incluindo exemplos e exercícios sobre classes, objetos, herança, polimorfismo e outros conceitos.

### nested_class

Exemplos e estudos sobre classes aninhadas (*Nested Classes*) em Python.

### polimorfismo_Agregacao_poo

Exercícios e exemplos relacionados aos conceitos de polimorfismo e agregação na Programação Orientada a Objetos.

### Estruturas_de_dados

Exercícios práticos sobre estruturas de dados e manipulação de coleções, incluindo listas, tuplas, concatenação e desempacotamento de valores (*unpacking*).

### Funcoes

Exemplos e exercícios sobre funções em Python, abordando definição de funções, parâmetros, argumentos nomeados, `*args`, `**kwargs` e outras funcionalidades.
